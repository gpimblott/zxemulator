Modern Power, Retro Soul

Core Accurate

Faithful Z80 CPU implementation including undocumented opcodes and R register behavior. Experience the 48K spectrum exactly as it was.

Controller Support

Plug and play with your favorite controllers. Supports Xbox, PlayStation, and generic USB gamepads via the Kempston interface.

Authentic AV

Real-time graphics and sound generation using SFML without the hassle of configuring complex plugins.

Save States

Never lose your progress again. Instant save and load functionality lets you freeze time and resume whenever you want.

Multi-Format

Supports SNA snapshots, Z80 snapshots (v1/v2/v3), and TAPE files (.tap, .tzx) for maximum library compatibility.

Cross Platform

Native support for macOS (including Apple Silicon), Linux, and Windows. Developed with portability in mind.

Now Running on Real Hardware Work in Progress

The emulator has been ported to the ESP32 microcontroller, putting a ZX Spectrum in your pocket for under £20.
The core Z80 CPU and display are working — keyboard input and filesystem support are still in development.

Roadmap — what’s still needed

  • Keyboard integration — hardware keyboard or GPIO button matrix so you can actually type BASIC commands
  • Filesystem / SD card — ability to load .tap and .z80 snapshot files from an SD card rather than only the embedded ROM

ESP32 @ 240MHz

Dual-core Xtensa LX6 running at full speed with performance compiler optimisations. Enough grunt to emulate the Z80 at authentic 3.5MHz.

ILI9341 TFT Display

240×320 SPI TFT screen driven via the TFT_eSPI library at 40MHz. The 256×192 Spectrum framebuffer is rendered and blasted over SPI in a single transaction per frame.

ROM Embedded in Flash

The 48K BASIC ROM is compiled directly into the firmware binary using ESP-IDF's binary embedding, so there's no SD card or filesystem needed.

Shared Codebase

The Z80 core, memory model, and tape loader are 100% shared between the desktop (SFML) and hardware (ESP32) builds — a single repo, two targets.

Build your own

All you need is an ESP32 dev board and a cheap SPI TFT display. Clone the repo and flash with a single script.

git clone https://github.com/gpimblott/zxemulator
cd zxemulator/esp32
./deploy_esp32.sh

Parts List

  • ESP32 Dev Board (e.g. DOIT ESP32 DevKitC)
  • ILI9341 2.8" SPI TFT (240×320)
  • USB cable & breadboard jumpers
  • ESP-IDF v5.5+ installed
